# 三种来源的发布前私有媒体

HTML、本地文件/GitHub 与外链现在先建立 `ft_publish_drafts`，不写入 `ft_works`。导入或构建完成后，在填写介绍时自动准备截图；托管 HTML/构建产物还准备不超过 8 秒的静音视频。作者选择候选封面、上传手动封面或明确跳过，并选择视频或明确不使用后，才可正式发布。外链目前只支持截图。

## 发布与安全边界

- 追加迁移 `0019_private_publish_media.sql`；生产与 staging 打开 `FUNTRACK_PREPUBLISH_MEDIA_REQUIRED=1`，服务端独立强制校验选择，旧页面直接提交会要求刷新。
- 草稿、截图和视频读取均须作者身份。草稿 HTML 不提供浏览路由，不进入 Feed、名片或试玩会话。捕获复用已有隔离云浏览器及外链 URL/DNS/重定向限制。
- 浏览器按文件实际 SHA-256 识别变更，服务端在最终发布时复核内容指纹及 build ownership。更换文件、来源或构建任务撤销旧选择；手动图片仍由作者选择。
- 草稿和捕获请求有独立幂等 ID。刷新和丢失响应复用已有记录；请求超时、并发占用、取消与迟到响应有界。草稿 24 小时过期，可以重新准备。
- 全部新旧捕获服务共用单一浏览器租约池；封面与视频分别沿用各自的 UTC 日/月预算，历史自动封面也纳入封面预算。预算记录在媒体清理后保留，不因重试或采用已选视频再次扣取。
- 正式发布把选中封面和视频复制到独立永久 key，和首个作品版本在同一数据库事务中公开。失去数据库提交响应时先读回；不删除已提交媒体。草稿清理仅删除临时路径。
- 新发布成功页只展示已确认结果，不再挂载首次生成封面/视频的控制器。已有作品的编辑/更新工具保留。
- 公共入口 `server.ts` 的修改仅限草稿服务注册与首次发布；`site.js` 的修改仅限上传表单、媒体选择和发布成功页。其他账号、名片与作品版本契约不变。
