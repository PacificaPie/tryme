# Feed 与发布链路迭代 · 2026-11-16

## 排序与规模

`GET /api/discover` 在完整作品集合中搜索、筛选、排序，再按游标分页；默认每次 12 件，最多 48 件。默认最新发布，也可选累计点赞或累计讨论。计数相同按发布时间、ID 排序。搜索支持名称、介绍、创作者。旧 `/api/works` 的最近 200 件接口为兼容保留，Feed、作者作品、自己的作品选择已迁移。

翻页固定首次请求时间，后续新发布、点赞、评论不会把新数据插入本次遍历。点赞取消目前物理删除记录，无法重建历史点赞快照，因此点赞排行在取消点赞时仍可能变动；前端去重并提供刷新。列表返回保留本次访问的已加载页、查询与滚动位置，最多缓存 8 个查询。

这不是个性化推荐。累计热度容易让早期热门作品持续领先；默认最新可提供基本曝光，但尚未处理同一作者连续发布、刷量、审核、曝光公平性。后续基于真实数据再评估作者打散、新作品探索位、时间衰减。本轮没有做高并发压测；超过 200 件的正确性测试不代表万级流量容量证明。

## 发布来源

- 本地：自包含 HTML ≤ 1 MiB，另选 PNG/JPG/WebP 封面 ≤ 2 MiB。
- GitHub：公开仓库根目录 `index.html`，或公开 HTML blob/raw 链接。解析默认分支后固定 commit SHA，匿名下载并形成同一种 HTML 草稿，然后复用发布和沙箱试玩。后续仓库更新不会自动覆盖已发布版本。
- 已有网站：含 GitHub Pages 的已部署 URL，在外站打开；不等于仓库导入，也不提供站内完成率。

GitHub 暂不支持私有仓库、多文件资源、安装依赖或构建。静态依赖扫描只做兼容性筛查，不能证明任意 JS 安全或所有游戏可运行；运行时仍受现有 opaque-origin iframe 与 CSP 限制。导入需要已有登录及同源 CSRF，只有固定 GitHub 官方主机，10 秒请求超时与 1 MiB 读取限制，不携带 GitHub 凭据。匿名 GitHub API 有共享额度限制。

## 样例与验证

新增六款自制演示：潮汐记忆、像素果园、折光弹球、拍点、四方数独、弧线投篮；连同原三款共九款。目录在 `/examples/more.html`。每款有可实际游玩的 HTML 和独立封面，演示作品不冒充外部创作者或真实热度。

- 单元测试 41 项通过；`npm run check` 通过。
- HTTP 集成 34 项通过，覆盖作品/版本/埋点、点赞/名片、评论、发现页、导入边界。发现页使用 207 件本地 SQL 测试作品及 2 件 HTTP 发布作品，验证 200 条之外的老作品仍可排名、同时间分页无重复、作者/形式/搜索条件、游标隔离和首次请求时间边界。
- GitHub 真实 resolver 与 HTTP POST 均读取成功：`mpaterakis/html-snakeGame` 的 `snakeGame.html`，SHA `377d3928d9e595b76dcd0ef8a871f2ab512b110b`，13,942 字节。测试项目随附完整 MIT notice：`tests/fixtures/github-snake-LICENSE.txt`。
- 浏览器本地实测：GitHub 读取 → 保存草稿并返回 → 发布 → 沙箱 Start 运行；本地投篮 HTML 与封面选择 → 发布 → 试玩、命中；翻页 12→24 件 → 打开作品 → 返回保留 24 件、查询及滚动位置；搜索后立即筛选不丢搜索词。
- 六款新游戏均打开并启动、执行其操作；数独实际完成终局。嵌入模式按 iframe 高度缩放等比画布，桌面与 390px 手机宽度可看到控件。

详细本地执行记录在忽略版本控制的 `.preview/local-*-integration.json` 和 `.preview/local-github-http-smoke.json`。浏览器查出并修复 GitHub 延迟响应覆盖本地文件、未读取 GitHub 时空值误判，以及筛选防抖与返回缓存问题。

## 视觉改动

缩小最新作品区，列数只随屏宽变化，统一文字对比度、间距、圆角与操作反馈；加入有空间预留的加载态、页内重试、明确刷新及触控目标。参考与推断边界见 `feed-scale-design-research.md`。没有宣称 CLS、可访问性或负载性能达到量化标准。
