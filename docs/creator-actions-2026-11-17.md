## 用户可见变化

- 我的作品与版本历史改用独立浮层。作品行的省略号是唯一菜单触发器；菜单内容不再撑开行高。提供屏幕边缘避让、键盘方向键、Esc 返回触发器、外部点击/焦点离开关闭；同时只打开一个菜单。
- 归档入口与已保存名片入口直接可见，移除只包着一个选项的“更多”。编辑作品后返回原详情及其列表/搜索上下文，不自动重新开始试玩。
- 名片列表在鼠标 hover 或键盘焦点进入时显示分享操作，本人另有重新制作、删除。触屏和窄屏直接显示操作。单作品封面限制在固定图片区域，避免盖住作者介绍。
- 分享弹窗同时提供邀请文案、链接、纯链接复制和系统分享。本人文案为“看看我在 Funtrack 制作的名片吧！”，分享他人名片使用对方名称。复制失败保留可选择的文本。
- 删除前说明名片与分享链接会撤下，作品和试玩历史保留。取消不写接口；重复提交只作用于同一名片，等待中去重，30 秒请求超时后可安全重试。重新制作不会重用已删除名片的保存标识。
- 取消整页位移和卡片 hover 上浮/图片缩放，保留短淡入、局部按压、菜单展开及弹窗收起。Feed 入场错峰最多 80ms；减少动态效果时关闭位移和重复动画。

动效参考 [Apple Motion](https://developer.apple.com/design/human-interface-guidelines/motion) 与 [Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility) 的连续性、稳定位置和 Reduce Motion 原则；没有把重度玻璃效果或长动画引入作品内容。

## API 和迁移

追加 `0012_card_deletion.sql`：仅向 `ft_cards` 添加 nullable `deleted_at`。不修改已有 snapshot JSON，不删除作品、游戏文件、版本、事件或名片行。

`POST /api/cards/:id/delete`：要求登录、当前作者所有权及同源 CSRF 校验。返回 `{cardId, deleted:true}`；重复请求幂等。没有权限或名片不存在均返回 `404 CARD_NOT_FOUND`。

删除后的详情、公开页面、公开 DTO 和公开封面均返回 404。列表和 `/api/cards/me` 不会因为删除最新名片而自动重新展示更早的名片；更早的独立分享链接按原有快照契约保留。旧保存请求重放返回 `409 CARD_DELETED`，前端引导重新生成预览。

公开名片页面/DTO/封面使用 `Cache-Control: no-store`，使后续读取检查撤销状态。已打开或另行保存的内容不会被远程抹除。
