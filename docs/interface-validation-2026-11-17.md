# 界面、归档与公开名片验收

环境：Cloudflare staging；2026-11-17。以下记录只描述实际验收，不代表正式域名或 Clerk production 已就绪。

## 已上线与实测

当前界面与公开分享版本 `7c4ef619-0728-49a6-bfc5-ce8c597309b5`。

- 浅色、深色、系统外观；真实 Clerk 表单切换外观后已输入内容保留。退出/登录流程未改账号归属。
- Feed、作品详情、数据面板、名片、编辑与发布界面共用语义颜色和交互时长。数据页的中文/英文与 360px 布局已检查。
- 真实游戏进入大屏、退出大屏，iframe 源保持不变；退出试玩返回作品。开屏加载不计作有效试玩。
- 数据面板切换时间、日/周粒度、指标与本人活动筛选，聚合和单作品页面可用。未知指标保持未知，没有补造留存或完成率。
- 作品手记、放映册都用四件现有作品生成并保存；返回选择页保留选择，放映册连点下一件到第三件，返回名片保留已浏览位置。
- 快速路由不闪骨架；慢请求、重试、离开页面与晚到响应由行为测试覆盖。没有以计时动画冒充真实进度。

## 免登录分享

- `/c/:cardId` 直接返回名片 HTML、标题、canonical 与 OG 元数据；原 `/site#/card/:id` 初访可跳到新地址。
- 在未登录的独立浏览器中，作品手记、放映册、旧卡中展厅均可打开并查看封面/简介。卡中展厅实际 3D 展开、进入、查看作品详情通过。
- 试玩动作进入 Clerk 登录；取消回公开名片。已有会话继续后进入名片固定的 v1，并开始加载游戏。
- 直接匿名请求 `/c/:id` 为 200；游戏文件和 `/api/me` 仍为 401。公开封面只允许该名片选中的历史资源，禁止私有列表和写接口由回归测试覆盖。
- 360px 公共页面没有横向溢出；中文/英文界面可切换。用户自己写的作品介绍不自动翻译。
- 没有新增匿名事件、匿名账号或公开试玩；这符合本轮“看名片免登录、试玩再登录”的决定。

## 仍需分开理解的边界

- 真实云端新账号的再次注册未重复执行；零作品页面采用真实页面 renderer 配合隔离测试数据，不能称为新增真实用户验收。
- Chrome 管理页曾出现 iframe 首次加载无响应，手动重新加载后可显示真实 3D；公开页面独立浏览器首载通过。保留超时/重载，继续观察首载表现。
- 自动开屏封面属于后续新增功能，验收结果另记；不能因为这里的 UI 验收通过就称截图链路已完成。
- 微信登录只完成可行性研究；当前仍用 Clerk 测试实例。正式域名、正式登录实例和微信申请不在本次上线结果内。
