## 免登录分享

- `/c/:cardId` 直接返回名片 HTML、标题、canonical 与 OG 元数据；原 `/site#/card/:id` 初访可跳到新地址。
- 在未登录的独立浏览器中，作品手记、放映册、旧卡中展厅均可打开并查看封面/简介。卡中展厅实际 3D 展开、进入、查看作品详情通过。
- 最新部署 `13c9a469`：Chrome 首访 `/c/71160f2c-1946-4d96-a85c-bfdaf5940fe8` 已直接显示真实 3D，无需手动重新加载；这不是 HTML 列表 fallback。
- 试玩动作进入 Clerk 登录；取消回公开名片。已有会话继续后进入名片固定的 v1，并开始加载游戏。
- 直接匿名请求 `/c/:id` 为 200；游戏文件和 `/api/me` 仍为 401。公开封面只允许该名片选中的历史资源，禁止私有列表和写接口由回归测试覆盖。
- 360px 公共页面没有横向溢出；中文/英文界面可切换。用户自己写的作品介绍不自动翻译。
- 没有新增匿名事件、匿名账号或公开试玩；这符合本轮“看名片免登录、试玩再登录”的决定。

## 自动开屏封面

- `0011_automatic_work_covers.sql` 已迁移，功能随 `13c9a469` 部署。新 Cron 传播期间排队，随后由 Cloudflare 定时器自主执行，没有本机 runner 或人工触发任务。
- 既有无封面 Snake 点击生成后 ready，新 HTML Prism 未选择封面也成功发布，随后自动 ready；两者均一次成功，平台完整任务耗时分别 3488 ms / 1710 ms。浏览器实见真实开屏 JPEG，未点击游戏开始。
- 两件作品各新增 metadata 并从 revision 1 升到 2，游戏版本 ID 不变；随后 Prism 归档升到 revision 3，封面与版本保留。
- 截图前后均为 32 个试玩会话，card_view / game_complete / outbound_click / play_start / session_end / work_view 六类事件计数全部一致；没有把截图当作试玩或访问。
- Browser Run 官方关闭事件确认两次均 `NormalClosure`，供应商会话时长分别 1973 ms / 991 ms，完成后活跃会话为 0。平台完整任务耗时、浏览器会话耗时和账号总账单是不同口径，实际总账单仍需后续监控。详见 [自动封面](automatic-covers-2026-11-17.md)。

- 真实云端新账号的再次注册未重复执行；零作品页面采用真实页面 renderer 配合隔离测试数据，不能称为新增真实用户验收。
