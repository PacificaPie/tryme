# 创作者主页、关注与头像（2026-11-17）

## 已选方案与体验

- 创作者主页使用「桌上名片」：身份与关注操作、独立可打开的名片封面、完整公开作品列表。各名片模板共用封面入口，不嵌入模板的导航或交互；精选作品仍出现在完整作品列表中。
- 关注绑定创作者账号。Feed 支持发现/关注切换，创作者目录支持全部/我关注的；作品搜索、类型与排序保留。本人无关注按钮。
- 主页访客入口、完整名片与匿名分享页均提供「用同款制作」。登录返回保留模板来源；确认后只继承模板和卡背样式，使用自己的资料和作品，现有草稿覆盖有明确提示。
- 账号菜单及本人主页提供编辑资料。头像支持 PNG/JPEG/WebP 上传、方形裁切与四款默认插画；自定义形象未实现。上传在用户保存时才发生，取消不写入。
- 头像更新用于实时主页、作品作者和评论。已保存名片保持原头像；保存名片不再覆盖实时个人资料。未保存预览中的头像明确传给服务端，换头像或重试不会把快照换成另一个头像，上传头像还须属于当前账号。
- 使用现有白灰底色、细边框、按钮圆角、系统字体和轻量过渡；移动端保留足够的触控区域。

## 实现边界

- 新增 `/api/creators`、`/api/creators/:id`、`/api/creators/:id/follow`、`/api/me/profile`、`/api/me/avatar`。
- 关注写入使用期望状态而非 toggle，避免重试反转。列表分页、关注 Feed 游标与缓存按访问账号和查询隔离；隐藏/归档作品不进入公开作品列表。
- 头像仅允许站内默认插画和带随机 ID 的公开图片资源；上传限制 2 MiB、4096×4096，静态 PNG/JPEG/WebP。浏览器输出 512×512 PNG。历史上传保留以支持已存名片。
- 展厅保留旧卡剪影，头像异步加载不阻塞交互；图片失败保留原剪影。SVG 插画声明固有尺寸，避免 Chrome 画布裁切只绘制局部。
- 数据迁移 `0013_creator_profiles_and_follows.sql` 为增量，增加头像引用、头像元数据、关注关系与索引；不改写作品或名片快照。
