# 作品更新与回滚：实现和验收

日期：2026-11-16。第一阶段已在本地实现和验证；版本功能及 0005 迁移尚未发布到生产。线上 GitHub 仓库导入功能已单独发布，生产源码基线为 `4ded3962320720375d6bb6750a965d98a901be3d`。没有修改《雨停之前》的源码或线上版本。

## 已实现

- 我的作品 → 更多 → 更新版本 / 版本历史；本地 HTML 和 GitHub 构建均可更新同一 workId。
- 隔离预览、更新说明、可选替换封面；省略封面继承当前版本。
- 不可变版本、历史试玩深链接、切换历史版本；单调 revision 防止旧请求在 v1 → v2 → v1 后误覆盖。
- 幂等重放返回原操作结果，不再次切换当前指针。R2 失败不切换版本；数据库结果不确定时优先保留可能已提交的文件。
- 旧会话、反馈、事件、名片保持原 versionId；新名片保存精确的预览版本。旧缓存名片需明确重新生成预览后采用新协议。
- 作品累计统计不再把跨版本事件标为当前版本数据。作品 createdAt、点赞、评论和原链接保持。

## GitHub 导入线上验证

已发布的独立第三方演示作品为 `8f7755d6-87d5-41b1-b980-7bf17688b560`，版本 `abfecc3f-9501-4d92-9a79-bd55bf101647`，真实构建任务 `9a9ee9f0-eb8f-4783-ab9e-7c26f8d681dc`。15 个源码文件经真实 Vite 构建，原始 dist 为 4 文件、223,207 bytes；封装结果为 229,573 bytes，本次构建总计 10.375 秒（工具链依赖已有缓存）。预览、发布、站内开始试玩、退出与返回均已验证，原作和依赖许可保留。

线上共享 IP 的 GitHub REST 匿名额度曾用尽；resolver 现仅在额度错误时读取官方公开 commit Atom feed，以 feed 的仓库身份和完整 HEAD SHA 固定版本，不猜测 main/master。该路径不提供描述或许可证摘要，实际许可仍从下载的固定源码读取并保留。

构建器仍是本机 Docker 按需运行，不是常驻云服务。一次性验证构建器已退出；已发布的游戏仍由网站托管。兼容范围及启动方式见 `repository-build-runner.md`。
