# 作品浏览、讨论与点亮收藏

本轮将发现页分为最新作品与其余作品列表，详情页集中媒体、作者、版本和一个试玩入口。设计依据及证据边界见 `product-surface-research.md`。

公开讨论使用独立 comments 表，提供根评论、单层回复和显式点赞状态。旧私密 feedback 不公开、不迁移，仍可从创作中心「互动 → 历史私密反馈」查看。新评论关联作品而非版本；不可当作某一版本的专属评价或已验证试玩评价。

第三个模板「点亮收藏」复用上传作品和作者信息，支持选择、预览、保存、分享及点作品试玩；无模型调用、无新付费步骤。展厅/桌面每组至多 6 件、名片至多 30 件，只渲染已选作品，少量作品居中，超过 6 件分页。封面完整留边显示，不以空框或虚构作品填满。

## 验证记录

- 本地浏览器：搜索无结果与清除筛选、按讨论排序、详情页单一试玩入口。
- 本地真实上传：Salt Run HTML 与封面，离开表单后草稿恢复，提交后打开试玩，游戏自然结束后进入讨论。
- 本地评论：发布、回复、点赞/撤销、刷新保留、草稿跨路由恢复、作品筛选、旧私密反馈隔离。
- 本地新模板：从选作品到选模板、预览、保存；桌面实际点击卡片进入游戏，退出返回；390px 单作品名片与讨论区无横向溢出。
- 后端本地 D1：评论 10 项、原 API 10 项、点赞/名片 7 项集成通过；最终新增 analytics.comments 断言另行运行。
- 数量边界和宽/竖封面的几何/控制器验证详见两个模板 README 与 tests；不是所有数量组合都逐一做了浏览器视觉验收。

上线保持既有 owner-private 访问范围。生产站不会导入本地验收用户、测试评论或测试作品。
