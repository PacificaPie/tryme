# 数据面板：从作品入口计数到创作者概览

本轮以全部作品为默认范围，依次呈现关键指标、时间趋势、同一访客群的试玩转化、作品比较。选作品后保留日期并支持版本筛选；统计定义集中折叠，不增加独立说明页。

## 指标选择

- PV 是作品页访问事件；UV 是期间内去重登录账号。总体 UV、周 UV 重新去重，不能相加作品或每日 UV。
- 打开试玩是创建的试玩会话；开始试玩需要收到首次可信输入。一个账号可以多次试玩，因此人数与次数分开。
- 新增页面可见试玩计时，从首次游戏输入起，到完成或退出止，页面隐藏暂停。平均时长只使用有有效新版结束回执的已开始会话；旧版缺失样本显示未知，不根据旧 elapsedMs 补算。
- 完成上报由游戏调用协议产生，不能自动等同通关、胜率或完玩率。暂不添加无依据的收入、获客成本或市场规模。
- 回访指所选期间至少两个 UTC 日玩过的账号，不能冒充次日/七日留存。
- 期间可选择最近 7 / 30 / 90 天及自定义范围，按天或周聚合，并与前一等长日历期间比较。包含今天时明确它尚未结束。
- 作品评论及点赞尚无版本归属，版本筛选时不编造该版本的社交数据。

## 时长与参考

参考 [Google Analytics 的用户参与时间说明](https://support.google.com/analytics/answer/11109416?hl=en-EN) 和 [GameAnalytics 指标定义](https://docs.gameanalytics.com/events-metrics-and-filtering/metrics/)，本项目将可见时间、开始人数、会话次数和完整结束样本区分显示。具体公式采用自己的埋点合同，并不宣称与这些服务的指标完全相同。

浏览器实现采用 [Page Visibility API](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API) 的 visibilitychange，避免把 iframe 获得焦点造成的 blur 当成离开。计时使用 performance.now，不使用后台受节流的 interval 累加。页面仍可见时的阅读和等待会被计入，因此它不是持续操作时间或反作弊证据。

时长仍依赖最终回执：断网关闭、浏览器被杀或一小时会话过期可能缺失。面板展示样本覆盖；不把缺失补成零。所有数据观察基于当前真实数据计算，不调用模型生成诊断。

接口与归因边界见 analytics-contract.md。无数据库结构迁移，也不改写既有事件。
