# Funtrack 推荐实验 v1

本轮落实用户确认的“试玩别人作品后点赞或反馈，给自己的作品少量加权”。已部署至 [独立测试站](https://funtrack-staging.zhayizha-pacificapie.workers.dev/site)，Worker 版本 `0a323078-abc1-4f94-84ca-f5de1a9f8fef`。仍使用临时域名与 Clerk 测试登录；未改动原 Sites、production 库或独立云构建器。

这是全站共享的推荐排序，不是根据个人兴趣定制的信息流。默认 Feed 使用推荐，保留最新发布、最多点赞、最多讨论；公开作者页和旧 API 的默认仍是最新。

## 推荐规则

以下是可调的实验参数，集中在 `lib/funtrack/recommendation-service.mjs`：

| 项目 | 当前规则 |
| --- | --- |
| 新鲜度 | 最高 400 分，从作品首次发布起 30 天线性衰减至 0；更新版本不重置 |
| 新作品基础推荐 | 首次发布 7 天内，额外获得最多 200 分；每触达 1 位非作者账号减 10 分，20 位后归零 |
| 试玩信号 | 最近 30 天独立非作者试玩账号 × 10，最高 200；重复开局不累加 |
| 作者贡献 | 每次有效贡献起始 10 分，7 天线性衰减；其作品获得的贡献加分总计最高 40 |

总分最高 840，同分按首次发布时间、作品 ID 倒序。贡献分上限是固定 40 分，不是“曝光提升 40%”或固定名次。新作品无需先互动就有基础推荐优先级；没有足够访客时无法承诺最低浏览量。当前没有强制作者轮换、兴趣个性化、积分、等级或付费加权。

## 哪些互动计入贡献

先有服务器接收的试玩首次操作事件，24 小时内再点赞作品、发表根评论，或发送旧版私密反馈（喜欢／建议／问题均可）。对象须为别人当前公开的作品。

- 同一账号对同一作品终身最多一次；版本更新不重置。
- 同一目标作者每天最多一次，每个贡献账号每天总计最多三次，按 UTC 日期。
- 点赞、评论、反馈共享上限，并发请求在同一数据库事务中去重。
- 自己作品、只有详情访问、外链点击、评论点赞、回复以及试玩前的点赞不计入。
- 取消点赞不撤销已经发生的参与贡献；再次点赞不会再赚一次。内容不会因为负面建议而失去资格。
- 分数衰减按实际授予时间，历史互动不批量补算；超过 24 小时的旧互动重试不能补领。

同一作品的试玩开始记录尚在上传时，点赞与根评论先等待该请求确认，最多 2 秒。超时仍允许正常互动，但不保证贡献成立；后端仍要求先收到有效试玩记录，不伪造成功。

这只能约束单账号低成本重复互动，不证明真人、认真试玩或高质量反馈，也没有解决多账号互刷。测试阶段先观察有效外部试玩和反馈是否增加，不把赞数上涨直接当成功。

## 曝光口径与数据

只有主 Feed 卡片至少 50% 面积在可见视口中、连续 1 秒且页面在前台，才发出曝光记录。列表 API 返回、后台等待、短暂划过、作者页和创作中心不直接计入。每账号／作品／UTC 日期最多一条，切换排序、重复加载、返回缓存和重试不重复累计；排序字段记录当日首次被确认的曝光来源，不能用它做严格的排序 A/B 比较。

每批最多 24 条、每账号每分钟最多 240 条新记录。客户端有限重试使用原事件 ID，服务端确定账号和时间；切换账号后的旧队列会被拒绝。隐藏或删除的作品不会产生新曝光。本人曝光可以留在统计中，但不消耗新作品的外部触达扶持额度，作者也可筛除本人统计。

数据页提供 `Feed 曝光` 与 `Feed 触达人数`，支持时间范围、日／周趋势、作品比较和外部访客筛选。曝光次数是每日账号／作品去重记录数；触达人数在所选期间跨作品、跨日去重。曝光没有游戏版本归属，按版本筛选显示“—”。从本次上线开始采集，不补造历史。

本轮没有把曝光、点击和试玩串成因果归因漏斗，不能直接用总试玩除曝光宣称推荐转化率。

## 分页、兼容与回退

推荐第一页在同一数据库读取中记录作品、事件、曝光、贡献四张表的最大行号；分页游标保留这些边界和固定评估时间。新写入记录即使携带更早的服务器时间，也不会改变本次浏览的推荐分；刷新后才应用新数据。隐藏状态和作品搜索字段保持实时。旧点赞排序仍使用当前保留的点赞，其取消点赞场景不具备同样的快照保证。

迁移 `0009_feed_recommendations.sql` 仅增加曝光、贡献两张表和索引，不修改既有作品、版本、元数据、名片或历史事件。不改变发布、隐藏、同作者去重、版本更新和回滚。旧收录确认仍停用。代码回退可保留新表，避免丢失已采集数据。

## 验收路径

1. 登录后进入 Feed，确认默认“推荐”；切到“最新发布”，打开作品再返回，确认仍为最新。
2. 在 Feed 停留、滚动、刷新并切排序；数据页查看今天的曝光，确认同账号同作品当天只计一次。
3. 用 A 账号上传作品，用 B 账号试玩 A 的作品后点赞或评论；B 自己的公开作品得到少量推荐加分。重复点赞、评论、换版本不能叠加同作品贡献。
4. A/B 分别查看数据页，选择只看外部访客；新作品在没有互动贡献时也能进入推荐候选并获得基础优先。
5. 隐藏作品，确认不再进入 Feed；原作品链接、版本历史和旧名片仍可打开。
